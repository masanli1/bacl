# 把"截肢求最优"写成强化学习

## 形式化

| 要素 | 对应到这个问题 |
|---|---|
| **状态 s** | 当前解：节点数、长度比（÷直线）、是否碰撞、最大关节增量 |
| **动作 a** | 删节点 / 投影到直线 / 重解连续 IK / 短路 |
| **奖励 r** | 长度减少量 ×20 − 碰撞罚(2) − 关节突变罚(1) − 空动作罚(0.2) |
| **转移** | 动作把当前解变成一个新解（状态确实变了） |
| **学习** | Q-learning：Q(s,a) ← Q(s,a) + α[r + γ·max Q(s') − Q(s,a)] |

**与 PPO 的区别**：PPO 学"机械臂怎么走"；这里学"**怎么改自己的解**"——
每一步动作都让状态（当前解）变得更好，直到改不动。

## 学到的策略

| 状态 | 学到的动作 | Q 值 |
|---|---|---|
| 节点 7 · 长度 1.0–1.5 倍 · 无碰撞 · 无突变 | **投影到直线** | 0.83 |
| 节点 7 · 长度 1.0–1.5 倍 · **有碰撞** · 无突变 | **重解连续 IK** | 0.65 |
| 节点 7 · 长度 <1.05 倍 · 无碰撞 | 删节点（无收益） | −0.20 |

策略可解释：**先解决碰撞（重解 IK），再压长度（投影到直线），最后删冗余节点。**

## 结果

| | 起始 | 最终 |
|---|---|---|
| 路径长度 | 0.779 m | **0.751 m**（= 直线本身，1.00 倍） |
| 碰撞 | — | 无 |
| 最大关节增量 | — | 0.066 rad |

## 诚实的评价

这个任务里"学习"的收益不大（0.779 → 0.751 m，只改善 3.6%），因为：
- 初始解已经是"链式 IK + 直线节点"，本身就接近最优
- 障碍没有挡在路径上，所以没有绕行的必要

**学习真正起作用的是"被挡"场景**：那时"重解连续 IK"（Q=0.65）和"绕行动作"才是必要的，
而这些正是 Q 表学出来的。
