# 三段式结构化求解 vs 强化学习

按"固定位置 / 固定数量 / 不固定"三种节点把组合问题拆开，替代 RL 的盲目探索。

## 节点定义（机械臂语义）

| 节点类型 | 含义 | 是否参与搜索 |
|---|---|---|
| **固定位置** | 起点姿态 q₀、终点位置（用逆解求出对应关节角） | ❌ 不搜索，直接满足 |
| **固定数量** | 节点层数 K（机械臂一个动作一层，本例 K=6） | ❌ 数量固定，只决定结构 |
| **不固定** | 每一层选哪个关节向量 | ✅ 唯一搜索自由度 |

## 求解方式

```
第 0 层      = 起点（固定）
第 1..K-1 层 = 每层 N 个候选关节向量（不固定）
第 K 层      = 终点逆解（固定）

层与层之间：代价 = EE 位移 + 碰撞重罚（剪枝，不枚举）
最后：分层 DP 取最短路
```

## 结果（40 个随机场景，同一环境）

| 方法 | 严格成功率（到达 ≤0.05 且无碰撞） | 计算量 | 搜索空间 |
|---|---|---|---|
| **PPO**（250 轮，25.6 万步交互） | **0 / 40 = 0%** | 25.6 万次环境交互 | 无结构 |
| **三段式求解**（K=6, N=96） | **31 / 40 = 77.5%** | 平均 2.78 万次边检查 | 穷举规模 7.83×10¹¹ |

**关键对比：穷举是 7.83×10¹¹ 种组合，三段式只检查了 2.78 万条边——少了 7 个数量级。**

（K=8 时穷举规模升到 7.21×10¹⁵，成功率仍 31/40，说明结构不变时增加层数不提升，只增成本。）

## 为什么它比 RL 强

| | RL | 三段式 |
|---|---|---|
| 起点/终点 | 当成奖励去"学" | **直接满足**（不浪费样本） |
| 层数 | 隐式学出来 | **先验固定**（不搜索数量） |
| 每一步关节值 | 靠探索收敛 | **在有限候选集里做 DP** |
| 失败原因的定位 | 难（策略黑箱） | 清楚（IK 不收敛 / 无碰撞通路） |

40 次里失败的 9 次：**IK 不收敛 3 次、DP 找不到无碰撞通路 6 次**——都是可继续改进的具体项，不是"学不出来"。

## 与八二定律的关系

三段式天然符合 80/20：

- **80% 的工作量**放在"不固定"的关节值选择上（这才是真正需要精度的部分）
- **20% 的工作量**处理固定部分（起点/终点/层数），一次定死不反复
- 反过来，RL 把 100% 的预算花在学习"应该怎么动"，其中大部分浪费在重新发现"起点和终点在哪"这种已知信息上

## v3 修正：节点固定，碰撞靠"加动作"

v2 的做法是**插入新节点**——节点数会变，违反"固定数量"。v3 改为：

```
节点数永远 = 7（起点 + 5 中间节点 + 终点）
碰撞段 → 加一个动作：q(s) = 直线 + Σ aᵢ·exp(-((s-tᵢ)/w)²)·dᵢ
         动作只改"这一段怎么走"，不增加节点
```

### 结果（40 个场景，已加可行性闸门）

| 配置 | 成功率 | 节点数 | 平均追加动作 | 耗时 |
|---|---|---|---|---|
| 第一阶段也避碰撞 | **40/40 = 100%** | **恒为 7** | 0.1 | 27 s |
| 第一阶段不避碰撞、全靠加动作 | **40/40 = 100%** | **恒为 7** | 0.6 | **264 ms** |

**第二阶段成为主力后反而更快**（0.26 s/次）：不需要在 DP 里做大量碰撞检查，交给动作层去修。
